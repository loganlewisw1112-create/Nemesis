# NEMESIS Design Spec

Kalshi-native desktop command center. See unified execution plan for milestone delivery.

## Core concepts

- **Thesis Card** — atomic UI unit: external reality → implied prob → market price → net edge
- **Edge Theater** — unified ranked feed of thesis cards
- **Guardrail Cockpit** — 8-gate live-readiness SOP from operating plan
- **Profit Protection Layer** — qualification gates, no-trade regimes, profit lock, quarantine
- **Monitor Pods** — Flow Hunter, Weather Wing, Macro Pulse, Crypto Lead, Global Pulse, Infra Watch
- **Profit Station** — equity curve, fee waterfall, depth ladder, fill quality

## Defaults

- Demo + dry-run ON
- Kalshi-only v1
- Fresh build (EdgeFeed reference-only)
